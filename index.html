Record format · conformance test

Model Intervention
Records

Claims that an intervention changed a model's behavior are not comparable. Two reports can both be accurate and still disagree about what happened, because neither record states what was required not to change. MIR-1 specifies the fields such a claim must carry, and a mechanical test anyone may run on them without permission.

Three fields a report usually lacks

Each is checkable by a program that has never seen the intervention.

01

An executable falsifier

A program that recomputes the claim from the published observations and returns a boolean. The record does not ask to be believed; it asks to be run.

02

Invariants outside the score

At least one metric that the claim's own scoring function cannot see. A success that damaged something else gets a place to appear.

03

Lineage by content address

The base checkpoint is named by its bytes, so a record states the weights it started from rather than a model's name and a date.

Eleven verdicts, no aggregate

An aggregate is optimized rather than satisfied, and a score that can be optimized by damaging an unmeasured property reproduces the problem one level up. A record that carries a weight patch is measured by five further checks, reported in a separate block and never merged into the eleven.

11checks on a record
5on a weight patch, separate
4derived qualifiers
0aggregate score

The worked example in the repository is a published intervention re-recorded under the format. It fails exactly one check: no run states a cost. That failure is the paper's subject, and it is reported rather than repaired.

Check a record

Python 3.8 or later, no third-party dependencies, nothing to install.

git clone https://github.com/MIR-1-WSP/model-intervention-records
cd model-intervention-records/MIR
python3 validate.py records/MIR-R1.json   # 10 of 11; C-07 is the point
python3 ci/check.py                       # every expected answer, 21 of 21

The second command asserts the answers that must fail as well as the ones that must pass, and runs both implementations against each other. They are written from the same text in Python and Go, share no code, and agree byte for byte on every record, every mutation, and 400 random documents.

What it does not do

  • Verify that a claim is true
  • Assess importance, novelty, or safety
  • Rate an operator or a paper
  • Evaluate an invariant bound, which is declared
  • Certify anything; conformance is permissionless
