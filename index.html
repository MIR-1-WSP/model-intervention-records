Model Intervention Records

A conformance test for claims made in weight-space programming.

Claims that an intervention changed a model's behavior are not comparable. Two reports can both be accurate and still disagree about what happened, because neither record states what was required not to change. MIR-1 specifies the fields such a claim must carry, and a mechanical test anyone may run on them without permission: an executable falsifier, an invariant set with at least one metric outside the claim's own scoring function, and content-addressed lineage to a base checkpoint.

The test reports eleven individual verdicts and no aggregate score. A companion extends the weights payload with a composable Weight Patch and five further checks; another adds four report-only qualifiers. A published intervention is re-recorded as the worked example, and it fails exactly one check: no run states a cost.

Check a record

The validator runs on Python 3.8 or later with no third-party dependencies. Nothing needs to be installed.

git clone https://github.com/MIR-1-WSP/model-intervention-records
cd model-intervention-records/MIR
python3 validate.py records/MIR-R1.json
python3 ci/check.py

The first command ends in RESULT: FAIL (1 of 11): the failure is cost disclosure, and it is the paper's subject rather than a defect in the example. The second runs every expected answer, including the ones that must fail.

What it does not do

It does not verify that a claim is true, and it does not report importance, novelty, evaluation quality, operator reputation, model safety, or desirability. It checks that a claim is stated in a form another party can check. Invariant bounds are declared, not evaluated. Conformance is permissionless: there is no certification authority and no mark to license.
